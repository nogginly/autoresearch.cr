## Quick start

1. Install Crystal 1.22 or later. On Linux, also install OpenBLAS (`apt-get install libopenblas-dev`).
2. Install the shards and build the linter: `ops up`, or `shards install`.
3. Run the tests:
   ```bash
   ops test
   ```
